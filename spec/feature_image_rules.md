# coffeetableviz feature image rules

This file is the source of truth for story feature artwork used on coffeetableviz.com.

## Core rule

The feature image must communicate the **specific approved editorial story or tension**, not merely the broad subject area. State the visual metaphor before generation and reject a generic category scene that could fit an unrelated post.

## House palette

- **Background:** light grey `#F3F4F6` by default, matching the coffeetableviz blog/chart colour scheme.
- **Primary artwork:** black and charcoal.
- **Accent:** one restrained muted-red accent, normally `#C44E52`.
- Warm cream/off-white paper is **not** the default background. Use a different background only when the story genuinely requires it and Adam explicitly approves the exception.

## Composition

- Square 1:1.
- Strong negative space and clear silhouette/readability at thumbnail size.
- Stencil, linocut or screen-print character is preferred for editorial illustration.
- Keep the composition crop-safe for both card and hero use.
- Avoid decorative detail that does not help tell the approved story.

## Content safeguards

- No text rendered inside the illustration unless explicitly required.
- No watermarks.
- No franchise or company logos.
- Avoid recognisable actor/celebrity likenesses unless Adam explicitly requests one.
- Use symbolic references rather than copyrighted characters.

## Publication QA

Before publication verify that:

1. the concept matches the approved story;
2. the final image follows the house palette, including the `#F3F4F6` background rule;
3. the feature image, alt text and saved prompt describe the same concept;
4. the image is square, crop-safe and readable at card size;
5. the exact approved asset is the one referenced by the Jekyll post.
