# 538 Chart Template (LOCKED)

## Canvas
- Width: 12.0
- Height: 8.5
- Aspect ratio fixed (~1.41)

## Background
- Full canvas background: light grey (#F3F4F6)
- Plot area: same light grey (NO white plot area)

## Spacing & Layout
- Generous padding on all sides
- Title must not touch edge
- Subtitle must not overlap title or chart area
- Increase gap between title and subtitle where needed

## Titles
- Left-aligned
- Must stay within chart bounds
- Must not wrap into subtitle or plot area

## Gridlines
- Horizontal gridlines: ON (subtle)
- Vertical gridlines: optional (only when explicitly enabled)
- Gridline style consistent across axes

## Axes
- Minimal axis styling
- Clean labels
- No clutter

## Annotation
- Must remain INSIDE plot area
- Must not overlap key data marks (bars/lines)
- Positioned with intent (not default placement)

## Colours
- Follow 538 style principles
- Override only when explicitly defined

## Output Rules
- Export PNG
- Maintain exact canvas ratio
- Ensure consistent padding on all edges
