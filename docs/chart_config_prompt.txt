I am using a locked 538-style Python chart rendering system.

Your job is to analyse a dataset and generate a complete `CHART_CONFIG` dictionary for my renderer.

## INPUT
I will provide a CSV file and its repo filename/path.

## YOUR TASKS

1. Inspect the dataset structure.
   - Identify the correct data file path I provide
   - Identify x column
   - Identify y column
   - Detect whether a series column exists

2. Choose the best chart type:
   - `line` → time series / continuous trend
   - `bar` → category comparison
   - `dot` → ranked comparison
   - `scatter` → relationship between two numeric variables

3. Identify the strongest single story in the data.

4. Decide whether annotations are needed:
   - `reference_lines` only if genuinely useful
   - `highlight_points` only if there is a clear standout point
   - `auto_end_labels` should usually be used instead of manual end labels

5. Generate a full `CHART_CONFIG` dictionary using the exact schema below.

## REQUIRED SCHEMA

Return a Python dictionary called `CHART_CONFIG` with these fields:

- `data_file`
- `data_format`
- `chart_type`
- `title`
- `subtitle`
- `source_text`
- `footer_left`
- `vertical_gridlines`
- `x_col`
- `y_col`
- `series_col`
- `value_col`
- `xlim_right_pad`
- `sort_descending`
- `series_style`
- `series_overrides`
- `reference_lines`
- `highlight_points`
- `auto_end_labels`
- `end_labels`

## IMPORTANT SCHEMA RULES

- Always include:
  - `"data_file": "data/<filename>.csv"`
  - `"source_text": "Source: ..."`
- Use American spelling for renderer keys:
  - `color` not `colour`
- For wide data:
  - use `data_format = "wide"`
  - use `x_col` and `y_col`
- For long data:
  - use `data_format = "long"`
  - use `x_col`, `series_col`, and `value_col`
- `reference_lines` entries must use:
  - `y`, `label`, `color`, `linestyle`, `linewidth`, `label_x`, `label_offset`
- `highlight_points` entries must use:
  - `x`, `y`, `label`, `color`, `dx`, `dy`, `ha`, `size`
- If no annotations are needed, return:
  - `"reference_lines": []`
  - `"highlight_points": []`
  - `"end_labels": []`

## STYLE RULES

- Keep charts clean and editorial
- Prefer minimal annotations
- Never include placeholder or test text like:
  - "Test chart"
  - "Baseline"
  - "Peak test point"
- Titles should be short and message-led
- Subtitles should be concise and explanatory
- Use:
  - `"footer_left": "Adam Green | coffeetableviz"`
- Default primary color:
  - `#1F8FA8`
- Highlight color only if justified:
  - `#C44E52`
- For bar and dot charts:
  - `"sort_descending": True`
- If unsure, choose simplicity over complexity

## REQUIRED OUTPUT

Return only:

1. A short explanation of the chosen chart type and story angle
2. One Python code block containing the full `CHART_CONFIG = {...}` dictionary
