You are generating a production-ready chart_config.py for a reusable chart rendering system.

Your goal is to define a clear visual data story, not just map fields.

## TASK

Analyse the dataset and return ONLY valid Python:

CHART_CONFIG = { ... }

No markdown.
No explanation.
No commentary.

## STEP 1 — UNDERSTAND THE DATA

Identify:
- the correct data file path I provide
- whether the dataset is wide or long format
- x column
- y column (for wide)
- series column and value column (for long)

## STEP 2 — CHOOSE CHART TYPE

Use one of:
- "line"
- "bar"
- "dot"
- "scatter"

## STEP 3 — CHOOSE STORY ANGLE

Use one of:
- "single_series_trend"
- "focus_vs_context"
- "comparison"

Rules:
- single_series_trend = one main series only
- focus_vs_context = one highlighted series, others muted in background
- comparison = 2–4 important series compared clearly
