# Stripe Study v2 — measured Bauhaus art and regression QA

**Status:** branch ready for user review. Implements the three Stripe Study decisions recorded in the November 2026 Charting template conversation. GitHub Pages remains the publication source of truth. No unapproved change to main.

## Visual differences and data contracts

### Stripe + Sun
- Remove the two lines below the old masthead and the competing in-art headings. Keep source footer.
- Move current editable/autogenerated headline into a **57px wide, decorative vertical back bar** at x=112. Fit/shorten safely within the vertical run; never spill outside it. It is editorial typography, not data.
- Draw source-value vertical bars from y=800 with heights `419 × source_value / selected_maximum`, common baseline and selectable small labels.
- Draw a **data-derived** foreground filled circle: `filled_area / outlined_reference_area = actual_minimum / actual_maximum`. Neither circle position nor title bar height encodes anything.

### Flow Lines — nested S snake
- The previous equal-full-path-length U chart is retired. Do **not** claim the new snake curves have identical lengths or that coloured lengths *along the curves* measure values.
- Connect each selected source row to a corresponding bar with a continuous two-bend, sampled cubic S curve, deliberately styled as **unmeasured artwork**.
- The **measured** element is the straight, coloured right-hand segment, fixed at its record's x position, from **the shared y=365 zero baseline** to `y=365 + 237 × value / maximum`.
- The subtle shared zero rule is an axis reference, unlike the removed decorative masthead line.
- Optional compact labels (11px) are attached to left starting points for up to 15 records, constrained to the printable area. A line or its measured bar remains tappable to recover the full label/value.
- Palette finishes and an explicitly selected source-category mapping may change colour, not the measured vertical height.

### Classic — stacked horizontal bars with circle
- The old tripled strokes per row are retired. Draw **one clean rectangular bar per record**, arranged in stacked horizontal rows.
- Every row starts at x=163 and bar length `696 × value / maximum`, preserving a common zero baseline and exact source ratios.
- A large background circle is **purely stylistic**, explicitly not a second measurement. It sits *behind*, never hides the bar endpoints.
- Draw 11px source names on the bars, preserving the **exact formatted numeric value** at the bar's right end where it fits. Long names may ellipsise; numbers may never be truncated. If there is insufficient space, the corresponding label/value is omitted and still available by tap.
- Retain the source footer and a small safely fitted editorial title. No in-art explanatory block, extra top rule or decorative triple lines.

## Source fixture

Official repo CSV: `archive/projects/2026-09-david-bowie-track-distributions/data/bowie_track_distribution_rows.csv`. Filter `album_title = Aladdin Sane`; label `track_title`; metric `duration_seconds`.

- Exactly **10** source tracks
- Actual maximum **Time (315 seconds / 5:15)**
- Actual minimum **Cracked Actor (181 seconds / 3:01)**
- Every Classic bar uses this same 10-record dataset; alternative numeric values and category choices remain live.
- With metric `spotify_streams` on the same album, **8 valid** recorded counts exist; two original tracks have no Spotify stream count and must be excluded/disclosed, never mapped to zero.

## Checks performed

1. Embedded JavaScript compiled after rewriting the three renderers.
2. Simulated DOM/Canvas with the real Bowie dataset: **10 vertical Sun bars**, one background title bar, vertically rotated title, one min/max area circle, **no old Sun internal explanation**. Actual heights matched the source values divided by the 315-second maximum.
3. **10 sampled S connectors** and **10 coloured measured right-hand segments**, all beginning at y=365. Measured heights matched `237 × value / 315`; no old "equal full paths" captions. The line-based tap hit region preserves the original source row.
4. **10 Classic bars** with one filled background circle, correct proportional widths, and integrated names and actual minute-second values (e.g. Watch That Man 4:30; Time 5:15).
5. Numerical boundary check for **1, 2, 8, 10, 14, 16, 24 and 64 rows**: S geometry stayed inside the printable canvas (x≈294–810, y≈290–709); no NaN/Infinity; right-hand bar heights exactly `237 × value / maximum`.
6. Live measure change to Spotify streams updated the current Classic design from 10 to 8 tracks, explicitly disclosed the two missing source values, and did not refetch the already-loaded CSV.
7. The PNG export action remained wired.
8. Changes are restricted to this Resource's single HTML file, documentation and source-based SVG design previews. No other Resource, site content, shared renderer, CI or global chart config is modified.
