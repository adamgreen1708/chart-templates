# UK population: 2026–2050 — coffeetableviz

Editorial story: **The UK is getting older. But not all at once.**

## Repo-first production

The ONS 2024-based principal source data are stored under \`data/\`. Three chart configurations under \`config/\` use the production \`src/render_538.py\` renderer and \`spec/538_template_rules.md\` house style.

Workflow: \`.github/workflows/render-archived-project.yml\`.
On push to the draft project branch, it:
1. runs \`scripts/build_chart_views.py\` for deterministic derived chart data with assertions;
2. renders all \`config/*.py\` via \`src/render_538.py\` into \`output/\`;
3. copies only explicitly mapped chart PNGs via \`publish_asset_map.csv\` to \`site/assets/charts/\`;
4. commits the generated data and PNGs back to the branch, for review and Jekyll PR QA.

These three charts are not uploaded from local renders. The archived output and site chart assets are produced in GitHub.

## Review and publication gate

- Short, light-hearted article and three-chart narrative: approved.
- Three rendered images: require GitHub Actions output and visual inspection before merge.
- Feature illustration: original approved single-scene Westminster Bridge asset is *not* generated by the chart renderer. **Still requires separately adding the exact approved illustration at \`site/assets/charts/uk_ageing_feature.png\`.** It must not be silently substituted or regenerated.
- Page image paths must exist on branch and Jekyll/mobile QA must pass; do not merge before all four paths are present.
- Publishing via GitHub Pages occurs only after explicit final approval and PR merge.
- House chart QA: zero-based comparison bars, exact units, equal safe margins, legible historical annotations, no clipping.

## Source and definitions

- https://www.ons.gov.uk/peoplepopulationandcommunity/populationandmigration/populationprojections/datasets/z1zippedpopulationprojectionsdatafilesuk
- https://commonslibrary.parliament.uk/the-uks-changing-population/

These are mid-year population **projections**, not observed counts. In chart 1, ages 0–104 are individual years while the 105–109 and 110+ grouped counts are **combined into a clearly labelled 105+ bucket**. Historical dates on the chart are cultural context, not causal explanations.

Corrections: the share aged 65+ in 2026 is 19.648919%, correctly displayed as **19.6%** to one decimal place.
