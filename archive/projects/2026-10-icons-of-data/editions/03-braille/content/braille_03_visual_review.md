## Encoding QA
- **Modern UK Unified English Braille (UEB), uncontracted examples only**; RNIB and UKAAF with the UKAAF-endorsed ICEB UEB code as reference, **not legacy US EBAE**.
- Verified braille cells: a = 1 (⠁); b = 1–2 (⠃); c = 1–4 (⠉); number sign = 3–4–5–6 (⠼); numeric 1 = sign followed by a cell (⠼⠁).
- **63 non-empty raised-dot patterns + 1 empty cell = 64 possible six-bit states.** Not a claim that there are 64 independent letters.
- Colour is a teaching device only (teal ordinary raised dot, restrained muted red numeric indicator), not part of tactile encoding.
- The *Decode the Icon* side profile is labelled an illustrative schematic, not an embossed sample or source photograph.
- Fonts and glyph coverage were checked; unsupported Braille font glyph in a tiny footer was replaced with clear words before export.
- The 1920px original charts and 390px preview were inspected after re-rendering. Text equivalents are planned for Jekyll even if figure footnotes are small on phones.
